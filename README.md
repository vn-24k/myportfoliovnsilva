## 🏗️ Visão Geral & Arquitetura

O portfólio foi arquitetado utilizando **Nuxt 3** e **Vue 3** no modo SSR/Híbrido, projetado com rigor estético e padrões modernos de frontend para apresentar aplicações e projetos de alta escala:

- **Framework Core:** Nuxt 3 (SSR + Nitro Engine)
- **Componentização:** Vue 3 Composition API com TypeScript
- **Estilização & Design:** Bootstrap 5, SASS customizado e paleta Dark Mode com acentos ciano e esmeralda
- **Acessibilidade & Interatividade:** Galeria interativa de certificados com visualização modal em alta resolução, navegação por teclado (WCAG) e suporte a gestos de toque (touch/swipe)
- **Otimização de Ativos:** Imagens compactadas com algoritmos sem perda perceptível e carregamento sob demanda (`loading="lazy"`)
- **SEO & Metadados:** Tags Open Graph, Twitter Cards e semântica estruturada para indexação precisa

## 🌟 Projetos em Destaque no Portfólio

### 1. [AI Command Center](https://portfoliocaetano.vercel.app/projects/ai-command-center)
- **Descrição:** Plataforma SaaS Enterprise para configuração, supervisão e execução rastreável de agentes de IA com isolamento multi-tenant por organização.
- **Tecnologias:** Next.js 15, React 19, TypeScript, Drizzle ORM (20 migrações), PostgreSQL, Better Auth, Webhooks Mercado Pago e testes E2E com Playwright.
- **Deploy:** [https://ai-command-center-silk.vercel.app](https://ai-command-center-silk.vercel.app)

### 2. [VNbaas](https://portfoliocaetano.vercel.app/projects/vnbaas)
- **Descrição:** Plataforma própria de Backend-as-a-Service e console de banco de dados com Editor SQL, busca semântica por vetores de IA (Gemini SDK), Realtime WebSockets, Storage e Auth.
- **Tecnologias:** Node.js Express, React 19, Tailwind CSS v4, Motion, PostgreSQL (`pg`), `@google/genai`.
- **Repositório:** [https://github.com/vn-24k/VnBaas](https://github.com/vn-24k/VnBaas)

### 3. Neural Shell
- **Descrição:** CLI orientada a inteligência artificial para automação de tarefas de desenvolvimento e rotinas de infraestrutura.
- **Repositório:** [https://github.com/vn-24k/neural-shell](https://github.com/vn-24k/neural-shell)

### 4. Strata Engine
- **Descrição:** Interface de telemetria e visualização para infraestruturas autônomas de computação cognitiva distribuída.
- **Deploy:** [https://strata-engine-phi.vercel.app](https://strata-engine-phi.vercel.app)
